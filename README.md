# r0wh4n/tap

Homebrew tap for [Klipvault](https://github.com/r0wh4n/Klipvault) — an encrypted clipboard manager for the macOS menu bar.

```bash
brew install --cask r0wh4n/tap/klipvault
```

Then press `⌘⇧V`.

To remove it:

```bash
brew uninstall --cask klipvault          # keeps your encrypted history
brew uninstall --zap --cask klipvault    # deletes it too
```
